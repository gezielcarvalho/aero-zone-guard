# Project charter

## Purpose

Demonstrate an airspace-construction assessment domain through a full-stack .NET 8 and Angular prototype, with a focus on document-submission lifecycle concepts.

## Portfolio value

The project is retained as an aviation-domain architecture showcase. It demonstrates C#, ASP.NET Core, Angular, REST API design, repository abstractions, container assets, and lightweight project analysis documentation.

## Current scope

- Submission-document CRUD API and Angular forms/listing.
- Status tracking for a simple submission lifecycle.
- In-memory Entity Framework Core persistence for development.
- Dockerfiles and Compose topology for local execution.

## Outside current scope

- Aviation-safety decisions, geographic/elevation calculations, or regulatory compliance.
- Authentication, authorization, multi-sector workflow, notifications, and feedback.
- SQL Server/MongoDB persistence, production operations, and external authority integration.
